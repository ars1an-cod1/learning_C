What is a pointer? 

Pointer = a variable that holds an address

int a=3; // a holds 3 

int*p=&a // p holds address of a 

&a--> address of a 

*p--> value at that address

Functions can get the copy of value

Send the address (&a) then the function can change to real a 



SWAP

A function we write 
Swaps the values of two variables

before :a=3 ,b=7 

swap(&a,&b);


after: a =7,b =3 ;



MODIFY_VALUE

A function we write 
Multiplies the value by 2 

before: a=7;
modifty_value(&a);

after: a =14;

Both get addresses (&a) , so they can change the real variables// Without addresses the function only gets copy, but real variables stays the same
