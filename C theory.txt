common file operations in C 

Opening  FILE FOPEN()

Closing a file fclose()


Return  value 


If the file is opened successfully returns a file pointer to it

If the file is not opened then returns NULL 


FILE OPERATIONS---


FILE* pointer type for an open file 
fopen("name", "mode" ): opens a file, returns NULL if its fail 
"r" = read (error if the file does not exist )
"w" =write (creates file, or deletes old contenent )
"a"= append , adds to the end (creates the file if its needed )
fclose(fp): closes file
